# SA-STF

Official implementation of **Semantic-Adaptive Diffusion for Dynamic Spatiotemporal Fusion**.

Our paper **“Semantic-Adaptive Diffusion for Dynamic Spatiotemporal Fusion”** has been accepted by **CVPR 2026**.
